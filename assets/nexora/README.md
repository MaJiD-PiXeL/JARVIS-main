# NEXORA assets

The mark, horizon, Manrope and Vazirmatn fonts were copied from the user's
NEXORA website project (`static/nexora` and `static/fonts`) at the user's
request. Original website files are unchanged. Font licenses are included.

Palette: Obsidian #08090B, Titanium #BFC3C8, Graphite #25282D,
Electric Blue #426BFF. The desktop GUI draws the mark directly from SVG.
