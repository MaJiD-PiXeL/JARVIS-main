# معماری

`main.py` فرمان‌های YAML و مدل فارسی را می‌سازد. `Assistant` جلسه، نام فعال‌سازی و حالت سیستم یا گفتگو را مدیریت می‌کند. فعال‌سازی با جست‌وجوی متن Vosk انجام می‌شود؛ Porcupine در مسیر اجرا نیست.

`core/text.py` نویسه‌های فارسی را یکسان می‌کند. `CommandRouter` ابتدا تطبیق دقیق و بعد شباهت کل عبارت را بررسی می‌کند. فرمان‌ها به توابع `core/actions` متصل می‌شوند. `GeminiClient` فقط متن پرسش را ارسال می‌کند و ابزار اجرای فرمان ندارد.

همهٔ پاسخ‌های صوتی از `core/tts.py` عبور می‌کنند. هنگام صحبت، دریافت میکروفون متوقف و صوت قدیمی پاک می‌شود. `config.py` تنظیمات همراه برنامه و تنظیمات کاربر را ادغام می‌کند.
