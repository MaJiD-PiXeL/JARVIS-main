# محدوده کاربرد

جارویس فارسی برای اجرای فرمان‌های مشخص روی رایانه ویندوز طراحی شده است. تشخیص گفتار محلی است و فرمان‌های پایه به حساب ابری نیاز ندارند. گفت‌وگو به کلید Gemini و صدای طبیعی پیش‌فرض به اینترنت نیاز دارد.

این پروژه جایگزین کامل دستیارهای تجاری نیست. کنترل خانه هوشمند، برنامه موبایل، احراز هویت صوتی و رابط گرافیکی در نسخه فعلی وجود ندارند. مزیت اصلی، دسترسی به کد و امکان تغییر فرمان‌ها و تنظیمات است.
